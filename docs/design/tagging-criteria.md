# 自動タグ付けの判断基準

- 状態: 案（ユーザーの確認を待っている）
- 日付: 2026-10-27
- 関連: `docs/adr/0003-llm-operations.md`、`backend/src/tagging.rs`、`data/seeds/020_field_tags.sql`

タグは、トピックを**探しやすくする**ためのもの。全国の「#子育て・教育」のように、自治体をまたいで同じ分野の話題を見つけられるようにする。タグはトピックの評価や立場を表すものではない。

基準の置き場所は次のとおり。

- **各分野の定義**: `data/seeds/020_field_tags.sql` の `description`（この文書の「分野の定義」と同じ内容）。自動タグ付けの指示文に、そのまま入る
- **共通のルールと境界の決め方**: この文書と、`backend/src/tagging.rs` の指示文

どちらかを変えたら、もう一方も直す。変えたら評価（`cargo run -- eval tagging`）で確かめる。

## 共通のルール

1. **「何を決める・変える話か」で選ぶ。** 本文に出てくる言葉ではなく、議論の中心で選ぶ。例えば「子育て世帯向けの市営住宅」の中心は住まいで、子育ては対象の説明にすぎない
2. **分野は1〜3個。最も中心になる分野を最初に。** 関係が薄い分野は付けない。迷ったら少なく付ける（付けすぎると、絞り込みの役に立たなくなる）
3. **立場で選ばない。** 賛成・反対のどちらの立場の説明でも、同じ話題なら同じタグにする
4. **人物・団体・政党はタグにしない。** 首長・議員の名前が出てきても、話題の分野で選ぶ
5. **「議会・選挙」は、議会や選挙の仕組みそのものが話題のときだけ。** 議会で議論された・議員が質問したというだけでは付けない（会議録から作るトピックは、ほぼすべてが議会に由来するため）
6. **「財政・税」は、お金の配分や負担そのものが論点のときだけ。** 個別の事業にお金がかかるというだけでは付けない。予算の全体、税・使用料、補助金の制度のあり方、事業の費用の是非が中心の話題に付ける
7. **「公共施設」は、建物の整備・建て替え・統廃合・配置が論点のとき。** 施設で行う活動の内容が論点なら、その活動の分野にする（図書館の開館時間 → 文化・スポーツ、図書館の建て替え → 公共施設）

## 地区タグのルール

地区タグは、話題の**対象の地域**を表す。人を地区で分けるものではない（ADR 0002）。

1. **トピックが市内の特定の地区を対象にしているときだけ付ける。** 最大2つ
2. **市全体の話題や、地区が読み取れないときは付けない**
3. **地区の名前が出てくるだけでは付けない。** 例えば「黒羽の事例を参考に、市全体で〜」は市全体の話題なので付けない
4. **自治体名と同じ名前の地区に注意する。** 「大田原市」の「大田原」は市の名前で、地区ではない。地区の大田原は旧大田原町の区域（中心市街地を含む）で、「大田原地区」「市の中心部」など、地区を指していると読み取れるときだけ付ける
   - 大田原市の地区: 大田原・金田・親園・野崎・佐久山（旧大田原市を昭和の合併前の町村で分けたもの）、黒羽、湯津上（2026-10-27 に3地区から7地区へ）
5. **施設や地名から地区が分かるときは付けてよい。** 例えば雲巌寺は黒羽地区にある。ただし推測に頼らず、確かなときだけにする

## 分野の定義

| 分野 | 含むもの |
|---|---|
| 子育て・教育 | 妊娠・出産、子育て支援、保育園・幼稚園・認定こども園、放課後の居場所、小中学校の教育の内容と運営、給食、いじめ・不登校、奨学金 |
| 福祉・介護 | 高齢者・障害のある人・生活に困っている人への支援やサービス、介護、見守り、生活保護、ひとり親家庭への支援 |
| 医療・健康 | 病院・診療所・救急医療、健診・予防接種、医療費の助成、心と体の健康づくり、感染症 |
| 防災・消防 | 地震・水害などの自然災害への備え、避難・避難所、ハザードマップ、消防・消防団、救急車の体制 |
| 防犯・交通安全 | 犯罪の防止、防犯カメラ・防犯灯、詐欺の被害の防止、交通事故の防止、通学路の安全 |
| 交通・移動 | 路線バス・デマンド交通・鉄道などの公共交通、移動の手段の確保、運転免許の返納後の移動 |
| 道路・上下水道 | 道路・橋・歩道の整備と維持、除雪、上水道・下水道・浄化槽 |
| 公共施設 | 公民館・図書館・体育館・庁舎・学校の建物などの整備、建て替え、統廃合、配置、維持管理（施設で行う活動の内容は、その活動の分野） |
| 住まい・移住 | 住宅・市営住宅、空き家、移住・定住の支援、二地域居住、関係人口との関わり |
| まちづくり・地域 | 中心市街地のにぎわい、都市計画・土地利用、景観、公園、自治会・地域のつながり、地域おこし |
| 環境・ごみ | ごみの収集・分別・減量、リサイクル、自然環境の保全、地球温暖化対策、再生可能エネルギー、騒音・水質などの公害 |
| 農林水産業 | 農業・林業・内水面漁業（川の漁業）、担い手、耕作放棄地、鳥獣による被害、農産物の販売 |
| 仕事・産業 | 雇用・就職、企業誘致、商店・中小企業の支援、起業、働き方 |
| 観光 | 観光客の誘致と受け入れ、観光資源、観光のためのイベント、ふるさと納税の返礼品 |
| 文化・スポーツ | 文化財・歴史、芸術、スポーツ、生涯学習、地域の祭りや伝統行事 |
| 人権・共生 | 差別の解消、男女共同参画、多文化共生、障害への理解、性の多様性、ハラスメントの防止 |
| 市役所・行政サービス | 行政の手続きや窓口、デジタル化、広報、情報公開、市役所の組織と職員、市民参加の仕組み |
| 財政・税 | 予算・決算の全体、税金・使用料・手数料、市の借金と貯金、補助金の制度のあり方、ふるさと納税の制度 |
| 議会・選挙 | 議会の運営・定数・報酬・情報公開、選挙の投票環境や投票率（議会で議論されたというだけでは付けない） |

## 境界の例

| 話題 | タグ | 理由 |
|---|---|---|
| 高齢者の見守り | 福祉・介護 | 防犯の話ではなく、生活の支援 |
| 子どもの見守り（不審者対策） | 防犯・交通安全、子育て・教育 | 犯罪の防止が中心 |
| 通学路の歩道の整備 | 防犯・交通安全、道路・上下水道 | 目的は安全、手段は道路 |
| 障害のある人の就労支援 | 福祉・介護、仕事・産業 | 支援のサービスが中心 |
| 障害への理解を広める取り組み | 人権・共生 | 差別の解消・理解が中心 |
| 外国人住民への生活の案内 | 人権・共生、市役所・行政サービス | 多文化共生と窓口の案内 |
| 市民体育館の建て替え | 公共施設、文化・スポーツ | 建物が中心。使い道の議論が多ければ文化・スポーツを先に |
| 学校の統廃合 | 子育て・教育、公共施設 | 子どもの学ぶ環境が中心 |
| ふるさと納税の返礼品 | 観光、農林水産業 など | 返礼品の中身で選ぶ |
| ふるさと納税の制度・使い道 | 財政・税 | お金の配分が中心 |
| 太陽光パネルと景観 | 環境・ごみ、まちづくり・地域 | 再エネと景観の両方が論点 |
| 議会の議員定数の削減 | 議会・選挙 | 議会の仕組みそのもの |
| 市長が議会に提案した給食費の無償化 | 子育て・教育、財政・税 | 議会・選挙ではない。人物もタグにしない |
| 投票所の削減 | 議会・選挙、市役所・行政サービス | 選挙の投票環境 |

## 見直し

- 評価（`evals/tagging.jsonl`）の結果と、運営者が付け直したタグ（`assigned_by = 'admin'`）を見て、定義や例を直す
- 分野を増やす・まとめるときは、既存のトピックのタグの移し替えも計画する（ID を変えない）
