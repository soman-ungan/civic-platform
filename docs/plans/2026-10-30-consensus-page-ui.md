# 合意点のページの画面（合意点のトグル・地図の固定と拡大縮小・概要の吹き出し・トピック詳細のレイヤ）

## Context
合意点のページ（`2026-10-30-consensus-page.md`、PR #30）を作ったあと、ユーザーと画面を見直した（2026-10-30）。

## 決めたこと（2026-10-30 ユーザーと決定）
- **合意点**: タイムラインにあったときと同じく、見出しの1行だけを出し、押すと開く。開いた中身はページの中に伸ばす（枠の中でスクロールさせない）
- **これまでの議論**: 節の見出しと地図をページの上に固定し、その下のカードだけをスクロールする。地図の高さは画面の4割ほど
- **地図**
  - 最初はタグの一覧（名前と締め切ったトピックの数）。タグを選ぶとその地図。「← タグを選び直す」で一覧へ。合意点から来たときは、そのタグの地図をそのトピックを起点にして開く
  - ピンチ・ドラッグと「＋／−／元に戻す」で拡大縮小・移動（ライブラリを使わない）。点の大きさは拡大しても画面の上で同じ
  - 点をタップすると概要の吹き出し（タイトル・締め切った日・参加人数）。概要を押すとトピック詳細のレイヤ。吹き出しの「ここを起点にする」で起点を選ぶ
  - 起点を選ぶと、近傍の点と線を色付ける
- **地図の下のカード**: 起点が無いときは地図のトピックすべて（押すとそれを起点にする）。起点があるときは起点と近傍（押すと「まとめを見る」の候補に入れる・外す）。各カードに「詳細」（トピック詳細のレイヤ）。「まとめを見る（N件）」は下に固定
- **トピック詳細のレイヤ**: 合意点のページから開いたときだけ、下から伸びるレイヤにする（Next.js のインターセプトルートとパラレルルート。URL は `/{slug}/topics/{id}`、共有・再読み込みでは普通のトピックの画面）。上端のつまみで高さを2段（半分・全体）に変え、下まで引っ張るか「×」で閉じて合意点のページに戻る（地図の選択はそのまま）。中身は今のトピックの画面と同じ部品

## やること
1. トピックの画面の中身を部品に分ける（`components/topics/detail.tsx`）。普通の画面とレイヤの両方から使う
2. `app/[municipality]/consensus/layout.tsx` と `@sheet`（`default.tsx`・`(..)topics/[id]/page.tsx`）。レイヤ（`components/digest/sheet.tsx`。つまみ・2段・引っ張って閉じる・×・背景を押して閉じる）
3. 合意点のトグル（`components/topics/consensus-list.tsx`）
4. 地図（`components/digest/map.tsx`）: タグの一覧・固定・拡大縮小と移動・吹き出し・カード・下に固定のボタン
5. docs（ADR 0005 の画面の説明・overview・計画の記録）

## 実装時の変更点
- トピックの画面の中身を `components/topics/detail.tsx`（`TopicDetailView`）に分けた。ヘッダーの一番上の行（戻るリンク）は、普通の画面だけが渡す
- レイヤ（`components/digest/sheet.tsx`）は、つまみを押すだけでも半分と全体を切り替える。背景を押しても閉じる。上には全体の高さより少しだけ引っ張れる
- 地図: 合意点から来たとき（`?focus=`）は、起点にしたうえで概要の吹き出しも開いておく。拡大は8倍まで。ホイールでも拡大縮小する（ページのスクロールを止める）
- 地図の見出しの「← 分野を選び直す」で、タグの一覧に戻る
- 確かめ: frontend の lint と型チェック。開発サーバーで、タグの一覧 → 地図（カード）、`?focus=` で起点と吹き出し、トピックの画面を直接開くと普通の画面になることを HTML で確かめた。ピンチ・ドラッグ・レイヤの引っ張りなどの操作は、ブラウザが無いので確かめていない
- （あとから）カードをスクロールすると、地図の高さを画面の4割から2割弱まで縮め、上に戻すと元に戻す。縮んだら吹き出しは閉じる。カードの下に縮む分の余白を置く（ページが短くなってスクロールが押し戻され、地図が揺れないように）
- （あとから）地図は高さだけでなく幅も同じ倍率で縮め、縦横比を保ったまま枠ごと小さくする（中央寄せ）
- （あとから）縮むときの揺れを直した: 合意点のページのスクロールの位置の自動の補正（scroll anchoring）を切り、地図の枠の大きさは縮める前の大きさに倍率を掛けてその場で出す（縮んだ枠を測り直すと1コマ遅れる）。点を小さくし、起点の近傍を起点を中心にした薄い円で示す（半径はいちばん遠い近傍の点まで）
- （あとから、ユーザーの依頼）タイムラインからトピックを開いたときも、同じレイヤで開く（`(tabs)/@sheet/(.)topics/[id]`）。レイヤは `components/layout/bottom-sheet.tsx`、中身は `components/topics/sheet.tsx` に分けて両方で使う。閉じたら下のページを読み直す（レイヤの中で投票すると、タイムラインの参加の印や合意点が変わるため）
- （あとから、ユーザーの依頼）タイムラインから開いたレイヤは、最初から全体の高さで開き、上端を自治体名とタブのヘッダーの下端にそろえる（`BottomSheet` の `initialSize`・`topAnchorId`。合意点のページからは今までどおり半分で開く）
