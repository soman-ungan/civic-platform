# 「合意点」を「グループごとの特徴」の表にまとめる

## Context
トピック詳細の「みんなの意見」では、合意点（全グループで (A+1)/(S+2) ≥ 0.8 の意見）をカードで出し、その下に「グループごとの特徴」の表を出している。ユーザーの要望は、合意点を表にまとめることと、「あなたのグループ」の列を枠線で囲んだのと同じように、合意点の意見を枠線で強調すること。

ユーザーの選択:
- 枠の色は**金色（琥珀色）**。青い列の枠や、緑・赤の塗りと紛れない色にする
- 合意点の行は**表の先頭にまとめる**（group-aware consensus の大きい順）。残りの行は投稿順のまま

## backend
**変更しない。** 分析 API の `consensus[]`（statement_id、gac の大きい順）と `statements_by_group[]` をそのまま使う。

## frontend
### `frontend/src/components/group-table.tsx`
1. props に `consensusIds: string[]`（gac の大きい順）を追加する
2. **行の並び替え**: 合意点の行を `consensusIds` の順で先頭に置き、残りは今の投稿順のままにする
3. **合意点のかたまりを金色の枠で囲む**（「あなたのグループ」の列と同じく、外側だけを囲む）
   - かたまりの最初の行の上端と最後の行の下端: `border-t-2` / `border-b-2`（`amber-500`、ダークでは `amber-400`）
   - かたまりの左端（固定の意見の列）と右端（最後のグループの列）: `border-l-2` / `border-r-2`
   - かたまりの中の行の区切りは、他の行と同じ灰色の線
   - 見出しの下の灰色の線は、かたまりが先頭にあるときは消す（金色の上端と二重線にならないようにする）
   - 「あなたのグループ」の列と重なるセルでは、左右は青い列の枠、上下は金色の行の枠を優先する。すべての行が合意点のときだけ、最後の行の下端は金色にする
4. **合意点の行の意見のセル**に「🤝 合意点」の小さなラベル（金色）を付ける。色だけに頼らないため
5. **凡例**に、金色の枠の色見本と「合意点（どのグループでも8割以上が賛成）」を追加する。合意点が無いときは、凡例の代わりに「まだ、すべてのグループの8割以上が賛成している意見はありません。」を出す

### `frontend/src/components/analysis-panel.tsx`
- 「合意点」のカードの節を削除し、`GroupTable` に `consensusIds={view.consensus.map((c) => c.statement_id)}` を渡す
- タイムラインの「📌 みんなの合意点」（`consensus-pins.tsx`）は変えない
