# 画面の枠の直し（ヘッダー・フッターをスクロールで隠す・ログインをヘッダーへ・まちのお金と管理画面の固定の欄を薄く）

## Context
2026-11-08、本番（ベーシック認証つきの仮公開）を実機で見たユーザーの要望。スマホでは画面の縦が狭く、
固定のヘッダー・フッター・まちのお金の固定の欄が場所を取る。

## やること
1. **ヘッダーとフッターをスクロールで隠す・出す**（全ページ）
   - 下にスクロールしたら、自治体の画面のヘッダー（自治体名とタブ）とフッターをたたむ。上にスクロールしたら出す
   - 一番上・一番下に来たときも出す（フッターのソースコードのリンク（AGPL 第13条）にいつでもたどり着けるように）
   - 少し動いただけで出たり隠れたりしないよう、ある程度スクロールしてから切り替える
   - どの画面のスクロールの枠でも拾える1つの仕組み（document で scroll を capture）が `<html data-chrome>` を付け、
     ヘッダーとフッターはそれを見て高さを 0 にたたむ。「スクロールはページだけ」の作りは変えない
   - まちのお金の固定の欄・管理画面の見出しは隠さない
2. **ログインをヘッダーへ**: 「パスキーでログイン」「ログイン中」「ログアウト」を、自治体の画面のヘッダーとトピックの詳細のヘッダーの右上に
   （運営者には「管理画面」も）。フッターは「このサービスについて」（左）と「ソースコード（AGPL）」（右）の1行。
   フッターはすべてのページに出る唯一の場所なので、ソースコードのリンクはフッターに残す
3. **まちのお金の固定の欄**: 「◯年度」の文字を消す。「1人あたり｜総額」の切り替えを金額の左に置き、金額の見出しと、
   もう片方の金額（重複）を消す。人口は金額の下に小さく
4. **管理画面**: 「トピック｜意見」と「下書き｜公開待ち｜公開中」の2段を、「下書き｜公開待ち｜公開中｜確認待ち」の1つの切り替えに

## 確かめ
- lint・型チェック。スマホの大きさのブラウザで、スクロールで隠れる・出る・一番下で出る、を確かめて画面写真を撮る
- 本番に入れて、実機でユーザーが確かめる
