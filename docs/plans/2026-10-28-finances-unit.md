# 「1人あたり｜総額」の切り替えを、まちのお金のヘッダーに移す

## Context
「1人あたり｜総額」の切り替えは「これまでの推移」の欄の中にしか無く、ほかの欄は1人あたりだけだった。
ユーザーの依頼（2026-10-28）: 切り替えをヘッダーに移し、どの欄でも総額に切り替えられるようにする。

## やること
- URL に `?unit=total` を足す（既定の1人あたりは付けない。`?view=budget` と同じ扱い）。`lib/finance-view.ts` の `financesQuery` / `financesHref` に単位を足し、年度のチップ・決算と予算の切り替え・推移の棒のどれから変えても引き継ぐ
- ヘッダー（`finance-header.tsx`）に「1人あたり｜総額」の切り替え。大きな数字も単位に従う（もう一方は横の小さな文字に）
- 単位に合わせた金額の文字は `lib/money.ts` の `amountText(unit, 千円, 円)` 1つにまとめる
- 単位に従う欄: 推移（欄の中の切り替えは消す）・何に使ったか・お金の使い方で見る・どこから来たか（円グラフの中の文字も）・主な事業（カード・一覧の大きい数字。もう一方は小さく残す）・予算と決算
  - 予算と決算の1人あたりは、それぞれの人口で割る（予算はそれ以前で最新の人口）
  - ツリーマップの吹き出しは、今までどおり両方を出す
- 割合（%）と棒・面積の大きさは、単位によらず同じ

## 確認
- frontend の lint・typecheck・build
- 単位・決算と予算・年度を組み合わせて、各欄の数字が切り替わること（開発サーバーで取得して確かめる）

## 実装時の変更点
- 予算と決算の1人あたりは、人口を渡さず、API がそれぞれの人口で割った `per_capita` をそのまま使った
