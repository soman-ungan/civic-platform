# 「今年の主な事業」をツリーマップで見せる

## Context
まちのお金の「今年の主な事業」は、金額の順のリスト（分野のチップで絞り込み）だった。
事業は165件（R8）あり、金額の差がとても大きい（上位10件で事業の合計の55%、真ん中は約2,800万円）。リストだけでは、何にどれだけ使うかの全体がつかみにくい。

## ユーザーと決めたこと（2026-10-28）
- 中心はツリーマップ（面積で金額を表す）。2段にする
  - 1段目は分野ごとの四角。タップすると、その分野の事業のツリーマップに切り替わる
  - 事業をタップすると、事業名・金額・1人あたり・原本のページへのリンクが出る
- 新規・拡充の事業は、冒頭に横スクロールのカードで「今年の新しい取り組み」として並べる
- 分野をまたぐ事業（R8 で30件）は、両方の分野に出す
  - ツリーマップの1段目の面積は、同じお金を2回描かないように、最初の分野だけで数える（合計が主な事業の合計と合う）
  - 一覧と、2段目（分野を開いたとき）は、その分野が付いた事業をすべて出す
- **四角の中の名前は、インフォマーク（ⓘ）と同じく、タップしたときに吹き出しで出す**（ユーザーの提案）
  - 色だけで分野を見分けさせないため、名前が十分に入る大きい四角だけは短い名前を出す。下の一覧の分野のチップに同じ色の印を付けて、凡例の代わりにする

## やること（frontend だけ。API は変えない）
- `lib/treemap.ts`: squarified の配置の計算（外部のライブラリを使わない）
- `components/budget-treemap.tsx`
  - 1段目: 分野を金額の大きい順に7つまで色（`--series-1..7`）で出し、残りの分野は「ほかの分野」（灰色）にまとめる
  - 主な事業に入らない分（予算の全体 − 主な事業の合計）は「概要に事業として載らない分」として薄い灰色で出す
  - 2段目: その分野の事業。小さい事業は「ほか N件」にまとめる。上に「‹ すべての分野」と、分野の名前・合計・件数
  - 吹き出し: タップで開き、画面のどこかに触れると閉じる（`InfoTip` と同じふるまい）。分野の吹き出しには「事業を見る」
  - 四角は HTML の要素で並べる（色は CSS の変数、文字はふつうの文字の色）。四角どうしは 2px あける
- `components/budget-projects.tsx`
  - 冒頭に新規・拡充のカード（横スクロール。タブのフリックと取り合わないように `data-swipe-ignore`）
  - ツリーマップで分野を開くと、一覧もその分野に絞り込む（逆も）
  - 分野のチップに、ツリーマップと同じ色の印
  - 注記:「分野をまたぐ事業は、どちらの分野にも出ます。ツリーマップの面積は最初の分野で数えています」
- `finances/page.tsx`: 予算の全体（`budget.total`）を渡す
- トピックの詳細の「この分野の今年の主な事業」は、件数が少ないので今のまま
