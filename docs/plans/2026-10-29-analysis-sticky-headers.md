# 「みんなの意見」の見出しを固定し、グループごとの特徴の表は枠の中でスクロールする

## Context
「グループごとの特徴」の表は、意見が増えるとページを縦にスクロールするうちに見出し（グループ名・人数）が見えなくなる。
表は横スクロールの枠（`overflow-x-auto`）の中にあるので、見出しを `sticky` にしてもページの縦スクロールには効かない。

## 決めたこと（2026-10-29 ユーザーと決定）
- ページに固定する見出しは2段
  1. 「みんなの意見」（と「最新の分析を見る」）: 画面の上端。ページの最後まで外れない
  2. 各パネルの見出し（グループごとの特徴・グループの構成・このまちとの関わり方による違い）: 1段目のすぐ下。そのパネルが画面から出たら外れる
- 「グループごとの特徴」の表は、高さに上限のある枠の中で縦横にスクロールする
  - 縦: 見出しの行（グループ名・人数）を枠の上に固定。横: 「意見」の列を左に固定。左上の角はどちらにも固定
  - 枠の高さは画面の7割程度まで（表の上からでも、端まで行けばページのスクロールに移れるように。凡例まで行けるように）。表が低ければ表の高さ
- 見出しを別の表に分けて横の位置を JS で合わせる案は採らない（CSS だけで済む形にする）

## やること
- `frontend/src/components/analysis/sticky.ts`（新規）: 2段の高さと固定する位置のクラスを1か所で決める
- `panel.tsx`: 1段目を固定（背景つき）
- `group-table.tsx`・`group-composition.tsx`・`residency-dot-plot.tsx`: パネルの見出しを固定
- `group-table.tsx`: 表の枠を `overflow-auto` と高さの上限に。見出しの行を `sticky top-0`、左上の角は重なりの順を上に
