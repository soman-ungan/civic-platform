# まちのお金の表示の整理（決算と予算の切り替え・欄の構成・推移の予算・コード）

## Context
まちのお金の画面は、フェーズ5b（決算）と 5c（予算）で機能を足し続けてきたので、複雑になっている。
- **決算と予算の選び方が暗黙**: 決算があれば決算、無ければ予算を黙って出している。R6 のように両方ある年度では、予算の内訳は「予算と決算」の欄でしか見えない
- **年度によって欄が出たり消えたりする**: 「主な事業」「予算と決算」「財政の指標」は年度によって無い。前回のエラー（欄が減って落ちた）もこれが原因
- **推移は決算だけ**: 予算だけの年度（R8）を選んでも棒が無く、最後の決算の年度が強調される
- **コード**: `finances/page.tsx`（約300行）に、値の選び分け（`s ? … : b?.…` の連続）、欄の組み立て、ヘッダー、出典が集まっている。吹き出しの開閉の処理が `InfoTip` と `BudgetTreemap` で重複している

ユーザーと決めたこと（2026-10-28）:
- 推移には、予算だけの年度の棒を、同じ積み上げで薄く（斜線）足す。軸の下に「予算」と書き、「当初予算は補正予算を含まないので、決算より小さく出ます」と注記する
- 整理の範囲は「画面の構成」「決算と予算の切り替え」「コードの整理」（色の固定は今回はしない）

## 進め方
- 新しいブランチ `refactor/finances-view` で行う（PR #7 の上に積む。PR #7 のマージはユーザーが行う）
- 計画を `docs/plans/2026-10-28-finances-view.md` に保存して最初にコミットする

## 1. 決算と予算の切り替え（見ているものを選べるようにする）
- URL に `?view=settlement|budget` を足す（年度と同じく URL で持つ。共有・戻るで保たれる）
- ヘッダーの年度のチップの下、1人あたりの数字の左に、2つ並びの切り替え「決算｜予算」を置く
  - 両方ある年度だけ押せる。片方しか無い年度は、ある方だけを文字で出す（いまの「予算」の印と同じ見た目）
  - 既定は決算（あれば）。選んだ方が無い年度に移ったら、ある方を出す
- 切り替えに従う欄: 1人あたり・総額（ヘッダー）、「何に使ったか」「お金の使い方で見る」「どこから来たか」
- 年度のチップ・推移の棒のタップで年度を変えるときも、`view` を引き継ぐ（URL を作る関数を1つにする）

## 2. 画面の構成（欄を固定し、無いときは理由を出す）
欄は年度によらず、いつも同じ7つを同じ順で並べる。データが無い欄は消さずに、短い説明を出す。
1. これまでの推移（決算＋予算だけの年度）
2. 何に使ったか（切り替えに従う）
3. お金の使い方で見る（切り替えに従う）
4. どこから来たか（切り替えに従う）
5. 主な事業（いつも予算。題を「今年の主な事業」から「主な事業（予算）」にする。年度が今年とは限らないため）
   - 無いとき: 「この年度の予算の概要は、まだ取り込んでいません」
6. 予算と決算（両方ある年度）
   - 無いとき: 「決算は、年度が終わった翌年の秋ごろに公表されます」/「この年度の予算はまだ取り込んでいません」
7. 財政の指標（決算）
   - 無いとき: 決算の公表の時期を出す
- 欄が固定になるので、カルーセルの点の数・順番が年度で変わらない

## 3. 推移に予算だけの年度を足す
- backend `GET /finances` の `trend` の各年度に `kind: "settlement" | "budget"` を足し、決算の無い年度で、公開済みの予算がある年度を加える
  - 目的別は予算の `budget_items`、人口はそれ以前で最新のもの（`latest_population`、`backend/src/routes/finances.rs`）
  - 決算と予算の両方ある年度（R6）は決算を使う
- `finance-trend.tsx`: `kind === "budget"` の棒は、同じ色の積み上げに斜線の模様（SVG の pattern）を重ねて薄くし、年度の目盛りの下に「予算」。選んだ年度の値の表示にも「予算」と出す。注記を足す
- 間の抜けた年度（R7 は予算も決算も無い）は、詰めて並べる（目盛りの年度で分かる）
- `backend/tests/api_finances.rs` に、予算だけの年度が推移に入ることを足す

## 4. コードの整理（見た目は 1〜3 以外変えない）
- `lib/finance-view.ts`（新規）: `financeView(f, view)` が、その年度・切り替えで出す値（種類・総額・人口・人口の年度・1人あたり・目的別・性質別・歳入・歳入の総額）を返す。page の `s ? … : b?.…` の連続をここに集める。`financesHref(slug, year, view)` も置く
- `components/finance-sections.tsx`（新規）: 7つの欄の定義（id・題・説明・中身・無いときの文）を1か所にまとめる。page はこれを呼ぶだけにする
- `components/finance-header.tsx`（新規）: 年度のチップ・切り替え・1人あたり（page から移す）
- `components/finance-sources.tsx`（新規）: 下の出典の文（page から移す）
- `hooks/use-dismiss.ts`（新規）: 「画面のどこかに触れたら閉じる・同時に開くのは1つ」を、`InfoTip`（`components/info-tip.tsx`）と `BudgetTreemap`（`components/budget-treemap.tsx`）で共有する
- `finance-carousel.tsx`: 欄が固定になるので、いまの id で持つ処理はそのまま残す（安全のため）
- `finances/page.tsx` は、取得・ヘッダー・カルーセル・出典を並べるだけ（100行ほど）にする
