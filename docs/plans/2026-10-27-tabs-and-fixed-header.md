# タイムラインと「まちのお金」の UI の改善（スワイプ・固定ヘッダー・合意点の折りたたみ）

## Context
フェーズ5b（PR #5）で「まちのお金」を作った。ユーザーから UI について3つの要望が出た。
1. 「トピック」と「まちのお金」を、スワイプで行き来できるようにする
2. 自治体名・「まちのお金」・「みんなの合意点」・タグの分類をヘッダーとして常に表示し、トピックのカードだけをスクロールさせる。フッターも常に下に表示する
3. 「みんなの合意点」は最初は閉じておく。タップで枠が広がり、枠の中でスクロールする

今はページ全体がスクロールし、フッターは本文の下にある（`src/app/layout.tsx` の `min-h-full flex flex-col`）。
「まちのお金」はタイムラインのヘッダーの右のリンクで、ページは別のルート（`/[municipality]/finances`）。

## 方針
- **URL は今のまま**（`/otawara` と `/otawara/finances`）。共有された URL だけで開けるようにし、データの取得も今のまま各ページで行う
- **2つのページを「トピック｜まちのお金」のタブにする。** タブは常に見える場所に置き、スワイプは補助にする（スワイプに気づかない人でも行き来できるように）
- **スワイプは、横に大きく素早く動かしたときだけ**（横 60px 以上かつ縦の2倍以上）にする。横にスクロールするタグの列と、推移の図（タップで年度を選ぶ）の上では反応させない（`data-swipe-ignore`）
- **ページの切り替えは、React の `<ViewTransition>` で左右にスライドさせる**（Next.js 16 の `transitionTypes`。`node_modules/next/dist/docs/01-app/02-guides/view-transitions.md` の Step 3 のとおり）。対応していないブラウザでは、アニメーションなしで切り替わる
- 新しい依存は足さない

## 変更
### 1. 画面の骨組み（固定のヘッダーとフッター）
- `src/app/layout.tsx`: `body` を `h-dvh flex flex-col overflow-hidden` にする。フッター（`SiteFooter`）は `shrink-0` で常に下に表示する
- スクロールは各ページの中で行う。今の各ページの `<main>` に `min-h-0 overflow-y-auto` を足す（`src/app/page.tsx`、`not-found.tsx`、`error.tsx`、`[municipality]/topics/[id]/page.tsx`）。中身の幅（`max-w-md`、余白）は内側の div に移す
### 2. タブとスワイプ（`[municipality]` の2ページ）
- ルートグループ `src/app/[municipality]/(tabs)/` を作り、`page.tsx` と `finances/page.tsx` をそこへ移す（URL は変わらない）。トピックの詳細（`topics/[id]`）はグループの外のまま
- `(tabs)/layout.tsx`（新規）: 固定のヘッダーとして、都道府県名・自治体名と、タブ「トピック｜まちのお金」を表示する（新しい `TabNav`。`usePathname` で選択中を示し、`Link` に `transitionTypes` を付ける）。今のタイムラインのヘッダーと、まちのお金の「← 大田原市のトピック」は、このヘッダーに置き換える
- `src/components/swipe-nav.tsx`（新規・クライアント）: ページの本体を包み、タッチのスワイプで `router.push(..., { transitionTypes })` する。トピックの画面で左にスワイプすると「まちのお金」へ、まちのお金の画面で右にスワイプするとトピックへ移る
- 各ページを `<ViewTransition enter/exit>` で包む。スライドの CSS は `globals.css` に足す（ドキュメントの例の 60px のスライド）。システムの「視差効果を減らす」（`prefers-reduced-motion`）が有効なら動かさない
### 3. トピックの画面
- ページを縦の flex にする。固定する部分（合意点・タグの列）は `shrink-0`、カードの一覧だけが `flex-1 min-h-0 overflow-y-auto` でスクロールする
- `src/components/topic-feed.tsx`: タグの列と一覧を分け、一覧だけをスクロールの領域にする。タグの列は横にスクロールし、`data-swipe-ignore` を付ける。タグで絞り込んだら、一覧のスクロールを先頭に戻す
- `src/components/consensus-pins.tsx`: 最初は「📌 みんなの合意点（N件）」の1行のボタンだけを出す。タップで開き、中身は `max-h-[40dvh] overflow-y-auto` の枠の中でスクロールする。もう一度タップで閉じる（`aria-expanded`）。今の「もっと見る（残り◯件）」は、枠の中でスクロールできるので無くす
### 4. まちのお金の画面
- 固定のヘッダー（自治体名・タブ）の下は、全体をスクロールさせる。年度のボタンもスクロールの中に置く（ヘッダーを低く保つため）
- 推移の図（`finance-trend.tsx` の `<svg>`）に `data-swipe-ignore` を付ける

## 確認
- `npm run lint` / `npm run typecheck` / `npm run build`
- 開発サーバーで、次をスマホ幅で確かめる（ユーザーにも依頼する。この環境にはブラウザが無い）
  - ヘッダー（自治体名・タブ・合意点・タグ）とフッターが動かず、カードだけがスクロールする
  - 合意点は閉じた状態で始まり、タップで開いて枠の中でスクロールし、もう一度タップで閉じる
  - 左右のスワイプでページが切り替わり、スライドする。タグの列の横スクロールと、推移の図のタップでは切り替わらない
  - トピックの詳細・トップ・404 のページも、フッターが下に固定されたまま中身がスクロールする
- コミットは `feat(frontend): ...` を1つ。PR #5 に含め、計画の md の「実装時の変更点」に追記する
