# 「まちのお金」の UI の改善（説明の吹き出し・開閉・固定ヘッダー・推移の帯グラフ・性質別の4区分）

## Context
フェーズ5b（PR #5）の「まちのお金」を、ユーザーが総務省の PDF 版と照合した（数字はすべて一致）。
そのうえで、UI について次の要望が出た。
- 費目の短い説明を、インフォマーク（ⓘ）のタップで吹き出しに出す。どこかをもう一度タップすると消す
  - 対象は「何に使ったか」「どこから来たか」。財政の指標の、今は名前の下に小さく出している説明も同じ形にする
- 各欄を開閉できるようにし、開けることがひと目でわかるようにする（最初は「何に使ったか」だけを開く）
- 年度のボタンを1行に収め、横スクロールで選べるようにする
- 年度のボタンと「1人あたり」の数字を、固定のヘッダーにする
- 年度の推移は帯グラフ（積み上げの縦棒）にする。横軸は年度、縦軸は金額
  - 費目ごとに表示・非表示を切り替えられる。最初は全部を表示して、歳出の合計が見えるようにする
  - 1人あたりと総額を切り替えられる
- 「お金の性質で見る」（性質別）は、目的別との違いが分かりにくい。ユーザーと相談して、次の4つにまとめることにした。各区分の中身の説明も見られるようにする
  - 固定費・投資的・返済・その他

## 方針
- **backend は変えない。** 今の API（`/finances`）の目的別・性質別・歳入・推移で足りる
- **費目の説明と性質別の区分は、frontend の辞書に置く**（新規 `src/lib/finance-terms.ts`）
  - 決算カードの費目の名前は全国で共通なので、自治体ごとの違いは無い
  - 説明は中立に、意味だけを書く。地方財政の用語の一般的な定義（総務省「地方財政白書」の用語の説明など）に沿う
- **性質別の4区分**（`finance-terms.ts` で費目のキーを区分に割り当てる）
  - 固定費: 人件費・扶助費。法律や制度でほぼ毎年決まって出ていく
  - 投資的: 投資的経費。建物・道路などをつくる費用（普通建設事業費・災害復旧事業費など）
  - 返済: 公債費。借金の返済
  - その他: 物件費・維持補修費・補助費等・繰出金・積立金・投資・出資金・貸付金・前年度繰上充用金
  - 区分に無い費目が来たら「その他」に入れる（年度による費目の増減に耐えるため）
- **推移の色**（dataviz のスキル）: 目的別は13費目あるので、最新年度の上位7つと「その他」の8色にする（`references/palette.md` の検証済みの8色を、ライト・ダークの両方で使う）
  - 色は費目に付け、表示・非表示を切り替えても色は変えない
  - 文字は色で塗らず、凡例の色見本で示す
  - 積み上げの段の間は 2px あける
- 新しい依存は足さない

## 変更
### 1. 説明の吹き出し（新規 `src/components/info-tip.tsx`・クライアント）
- 見出しの横に ⓘ のボタンを置く。触れる範囲は 44px、`aria-expanded`、吹き出しは `role="tooltip"`
- タップで、その下に吹き出しを出す。画面のどこかに触れたら閉じる（もう一度 ⓘ に触れても閉じる）。同時に開くのは1つだけ
- 次の3か所で使う
  - `FinanceBars` の各行（目的別・歳入。「その他（◯項目）」の行には付けない）
  - 財政の指標（今の `INDICATOR_NOTES` は `finance-terms.ts` へ移す）
  - 性質別の4区分
### 2. 開閉できる欄（新規 `src/components/finance-section.tsx`）
- `<details>` と `<summary>` で作る。見出しの右に ▼ を出し、開くと回る。閉じているときは「タップで開く」と添える
- 最初は「何に使ったか」だけを開く。ほかの欄（推移・どこから来たか・お金の種類で見る・財政の指標）は閉じておく
### 3. 固定のヘッダー（`(tabs)/finances/page.tsx`）
- ページを縦の flex にする。年度のボタンと「1人あたり」の数字は `shrink-0` で固定し、その下だけをスクロールさせる
- 年度のボタンは1行の横スクロールにする（`overflow-x-auto`、`data-swipe-ignore`）。選んでいる年度が見えるように、開いたときにスクロールして寄せる
- 「1人あたり」は低い1行にまとめる（年度・1人あたり・総額・人口）
### 4. 推移の帯グラフ（`finance-trend.tsx` を書き直す）
- SVG で積み上げの縦棒を描く。横軸は年度、縦軸は金額（0 から）
- 上に「1人あたり｜総額」の切り替えを置く
- 凡例を兼ねた費目のチップ（色見本つき）で、表示・非表示を切り替える。最初は全部を表示する
- 棒に触れると、その年度の内訳と合計を下に出す（ホバーの代わり。スマホでも読める）。表の形の一覧も、今のとおり「数値の一覧」に残す
- 図の上ではスワイプに反応しない（`data-swipe-ignore`）
### 5. お金の種類で見る（性質別）
- 4区分の割合を1本の帯（積み上げの横棒）で見せ、その下に区分ごとの行を並べる（ⓘ で説明）
- 区分の行を開くと、中身の費目と金額が出る
- 欄の名前は「お金の性質で見る」から「お金の種類で見る」に変える。説明は「同じお金を、分野ではなく使い方の種類で分けたもの」とする

## 確認

- dataviz の `scripts/validate_palette.js` で、使う8色をライトとダークの両方で確かめる
- 開発サーバーで API の値と画面の数字が合うことを確かめる（例: 2024年度の固定費の割合 = (人件費 + 扶助費) ÷ 歳出合計）
- スマホ幅での見た目と操作（吹き出しの開閉、欄の開閉、年度の横スクロール、帯グラフの切り替えとタップ）は、ユーザーに確かめてもらう（この環境にはブラウザが無い）
- 計画を `docs/plans/2026-10-27-finances-ui.md` に保存してから実装する。コミットは `feat(frontend): ...`。PR #5 に含める

## 実装時の変更点
- **推移の色の検証**: 8色はライト・ダークとも検証を通った。ライトの3色（#1baf7a・#eda100・#e87ba4）は背景との対比が 3:1 未満のため、選んだ年度の内訳を文字で出す欄と「数値の一覧」で補う（dataviz の relief rule）
- **費目を全部は消せない**: 推移の費目のチップは、最後の1つは消せないようにした（何も描けなくなるため）。消した費目があるときは「すべて表示」を出す
- **ⓘ を開閉できる欄の見出しの中に置いたときは、欄を開閉させない**（ⓘ のタップでは、欄の開閉の操作を止める）
- **2024年度の4区分**（大田原市）: 固定費 42.6%・投資的 7.4%・返済 9.3%・その他 40.7%。API の値から計算したものと画面の表示が一致することを確かめた

## 修正（2回目）

ユーザーが画面で確かめたうえでの修正（2026-10-27）。計画（承認済み）:

### 原因（帯グラフが黒い）
`finance-trend.tsx` で、SVG の `fill` の属性に `var(--series-1)` を書いていた。
SVG の属性には CSS の変数が効かないので、色が既定の黒になった。

「お金の種類」の帯と凡例の色見本は、HTML の `style` で書いていたので、色が出ていた。
SVG では `style={{ fill: ... }}` にすれば、CSS の変数が効く。

### 方針
- **円グラフはドーナツ型にし、区切りは6つまでにする**（dataviz の anti-patterns: 円は全体の中の割合をひと目で見せるためのもので、区切りは6つまで）
  - 何に使ったか: 13費目あるので、大きい順の5つと「その他」にまとめる
  - お金の使い方: 5区分なので、そのまま
  - 近い値は円では比べにくいので、円の下に今の一覧（1人あたり・割合・ⓘ）を凡例を兼ねて残す。一覧の行には、円と同じ色の見本を付ける
  - 色は系列の色（`--series-1`〜）を順に使う。区切りの間は 2px あける
- **使い方の5区分**（`src/lib/finance-terms.ts` の `NATURE_GROUPS`）。名前は短く、説明は1文で書く
  | 区分 | 中身 | 説明 |
  |---|---|---|
  | 固定費 | 人件費・扶助費 | 職員の給与と、福祉の給付。毎年ほぼ必ず出ていく |
  | 流動費 | 物件費・維持補修費・補助費等・繰出金 | 委託や光熱費、補修、団体や別の会計への支出。毎年の運営に使い、見直しの余地がある |
  | 投資 | 投資的経費 | 建物や道路をつくる費用と、災害の復旧 |
  | 返済 | 公債費 | 借金の返済 |
  | その他 | 積立金・投資・出資金・貸付金・前年度繰上充用金ほか | 貯金や出資・貸し付けなど |
  - 区分に無い費目が来たときは「その他」に入れる（今のまま）
- backend は変えない

### 変更
1. **並び順と最初の開き具合**（`(tabs)/finances/page.tsx`）: 推移・何に使ったか・お金の使い方で見る・どこから来たか・財政の指標の順にする。最初は推移だけを開く
2. **推移**（`src/components/finance-trend.tsx`）
   - 色: 積み上げの段・色見本の `fill` を `style` で指定する
   - 費目のチップ: 1行の横スクロールにする（`overflow-x-auto`、`data-swipe-ignore`）。先頭に「すべて選ぶ」「すべて外す」を置く
   - 全部を外したときは、図の代わりに「費目を選んでください」と出す（今の「最後の1つは消せない」はやめる）
   - 選んでいる年度: 最初はヘッダーで選んだ年度にする（`selectedYear` をページから渡す）。選んだ年度の列の後ろに薄い帯を敷き、年度の文字を太くする。ほかの年度の棒は今のとおり少し薄くする
3. **円グラフ**（新規 `src/components/finance-donut.tsx`、SVG のドーナツ）
   - 真ん中に合計（1人あたり）を書く
   - 「何に使ったか」は、`FinanceBars` の代わりに、円と色見本付きの一覧（`FinanceBars` に色見本を出す指定を足す）にする
   - 「お金の使い方で見る」は、`FinanceNature` の帯を円に替え、区分の行に色見本を付ける。行を開くと中身が出るのは今のまま
   - 円の区切りには触れられるようにし、触れると、その区切りの名前・額・割合を真ん中に出す（スマホでも読めるように）
4. **用語**（`src/lib/finance-terms.ts`）: 5区分にする。名前と説明を上の表のとおりにする。欄の説明を「同じ歳出を、使い方で分けたもの（性質別）」にする
