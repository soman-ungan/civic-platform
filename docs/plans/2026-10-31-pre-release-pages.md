# 公開の前に要るページと機能

## Context
機能がそろっているかを overview・当初の構想・ADR と突き合わせたところ、公開に要るのに無いものがあった（2026-10-31 ユーザーと決定。問い合わせはメール、退会では票と意見を残す）。
運営者への知らせはフェーズ7（サーバーとメール）で、選挙・議員のページはアイディアと計画を別に作ってから決める。

## やること

### 1・4. このサービスについて・利用規約・プライバシーポリシー
- `/about`・`/terms`・`/privacy`（自治体によらないので自治体の URL の外）。静的なページ（TSX）で、最後に改定日
- 文章は Claude が下書きし、運営者名など知らないところは「【要記入】」で残す。法的な文書なので、公開の前に専門家に確かめてもらう
  - about: 目的・Polis の考え方・原則（分断を生まない・お金で議論を変えない・AI の使い方）・運営者・ソースコード・収支の公開
  - terms: 投稿の決まり（ADR 0007 の基準）・禁止事項・投稿と票の扱い（匿名のまま分析に使い、取り消せない）・免責・行政資料の出典・改定
  - privacy: 集めるもの・集めないもの（年齢・性別・地区は集めない）・Cookie `cp_uid`・パスキー（公開鍵と ID だけ）・関わり方・AI（Anthropic）に送るもの・公表の秘匿（5人未満）・退会・問い合わせ先
- フッターにリンク

### 2. 問い合わせ
- `.env` の `NEXT_PUBLIC_CONTACT_EMAIL` を `mailto:` で出す（フォームはサーバー・メール送信・迷惑な投稿の対策が要るため）。用件の例（引用の訂正・意見の削除・不具合）を添える。未設定なら出さない

### 3. アカウントの削除（退会）
- `DELETE /api/auth/me`: その人のパスキー・関わり方・`registered_at`・運営者の印を消し、Cookie を消す（次から新しい匿名の参加者）
- 票と意見は残す（もとから誰のものかを返さず、パスキーを消すと残る ID はただの乱数になる。分析も壊さない）。意見そのものを消したいときは問い合わせから運営者が対応する（規約に書く）
- 画面: フッターのアカウントの欄から、確認を経て消す。端末のパスキーは端末の設定から消すよう案内し、対応するブラウザでは `PublicKeyCredential.signalUnknownCredential` で端末にも知らせる。運営者が消すときは、運営者でなくなることを警告する
- api.md・schema.md・ADR 0006 に追記

### 5. 共有したときの表示
- `NEXT_PUBLIC_SITE_URL`（`metadataBase`）
- ページごとの題と説明（`generateMetadata`）: トピックは「{題} | {自治体名}」と説明の冒頭、タイムライン・まちのお金・合意点・まとめは「{自治体名}の〜」
- Open Graph と X のカード（題と説明だけ。画像の自動生成は日本語フォントの同梱が要るので見送り）
- `robots.ts`: `/operator` と `/api` を除外

### 確かめ
- `cargo test`（退会のテストを足す）・clippy・fmt、frontend の lint・型チェック・`npm run build`
- 本番ビルドで各ページの `<head>` の題と OG を確かめる
- docs: overview・api.md・schema.md・`.env.example`・CLAUDE.md

## 実装時の変更点
- フッターは常に出るので1行に収めるため、「AGPL-3.0-only で公開しています」を「このサービスについて」のリンクに替え、ソースコードのリンクを「ソースコード（AGPL）」にした。利用規約・プライバシーポリシー・問い合わせは about（と各ページの下）から開く
- 問い合わせは `/contact` を作らず、about の節（`/about#contact`）にした
- 退会はアカウントのページ `/account`（フッターの「ログイン中」から開く）。ログアウトもここに置いた。`/account` は検索エンジンに載せない
- パスキーを作る選択肢（投票の前・投稿の前）の下に、規約とプライバシーポリシーへの同意の一文を足した
- 題は「題 | 市民参加プラットフォーム」（root の title の template）。トピックは「{題}（{自治体名}）」。共通の部分は `lib/metadata.ts` の `pageMetadata`（子が openGraph を書くと親の分がまるごと置き換わるため）
- 公開の前に埋めるところは画面に黄色の【要記入】で出る: 運営者名・収支の公開先・管轄の裁判所・アクセスの記録の保存期間・Anthropic の API のデータの扱い・サーバーの事業者と国（overview のフェーズ7に書いた）
