# タイムラインの設計 B（最初の意見の数・提案した人の投稿数・この分野のお金）

## Context
タイムラインの設計の B（A は `2026-10-30-timeline-flow.md`）。
- Polis 本家は最初の意見（seed）を10件以上（25〜40件が望ましい）と勧め、1人の投稿数に上限を設けない。このプロジェクトは議会のトピックの最初の意見を AI に3〜5件作らせ、市民の提案は1〜3件（提案した人の3件に数える）、参加する人は1トピック1件
- 議会のトピックの「この分野のお金」は、会議の年度にかかわらず最新の決算（1人あたり）と最新の予算を出している（2026-10-28 のユーザーの依頼の備忘）

## 決めたこと（2026-10-30 ユーザーと決定）
- **この分野のお金**: 予算・決算ともに総額で出す（1人あたりは出さない）。歳出に占める割合は残す
  - 議会のトピックは会議の年度に合わせる。予算の年度は会議の日の年（1月の会議だけ前年）。第1回定例会（2〜3月）は翌年度の当初予算を審議する会なので、こうなる
  - 決算は、その予算の年度より前の、取り込み済みで一番新しい年度（会議の時点で分かっていた最新の決算）
  - その年度の予算が無ければ、予算の欄は出さない（年度のずれた数字を並べない）
  - 市民の提案のトピック（会議が無い）は、今と同じく最新の年度
- **議会のトピックの最初の意見は、議会で出た主張をすべて採る**: AI への指示を「3〜5件」から「議会で出た、立場や中身の違う主張をすべて（言い換えは1件にまとめる）」に。上限は設けず、15件を超えたら捨てずに運営者に知らせる（AI の出力が壊れたときの歯止め）
  - 分析を開く条件は「最初の意見すべてに投票」なので、主張の多いトピックほど分析までの投票が増える。多すぎるものは運営者が下書きの確認で減らせる
- **市民の提案の最初の意見は1〜10件**（Polis の勧める10件以上の下限）。**最初の意見は提案した人の3件に数えない**。公開のあと、提案した人だけが新たに3件まで投稿できる
- 参加する人は1トピック1件のまま

## やること

### Step 1 この分野のお金（backend `interface/api/finances.rs`、frontend `components/topics/finances.tsx`）
- `for_topic` に年度の決まりを入れる: 出典の最初の会議の日（`documents.held_on`）があれば、予算の年度＝その年（1月なら前年）、決算＝それより前で一番新しい取り込み済みの年度。無ければ今までどおり最新
- 予算は、その年度の公開済みの予算だけ。無ければ出さない
- 画面: 決算の費目を総額（千円の表記。割合はそのまま）に。見出しの「今年の主な事業」を、その年度の主な事業に

### Step 2 議会のトピックの最初の意見（`ingest/minutes/extract.rs`）
- 指示文の「3〜5件」を「議会で出た、立場や中身の違う主張をすべて」に
- `MAX_STATEMENTS`（5件）を、捨てずに知らせる目安（15件）に変える
- 共同作業の手順（`.claude/commands/import-minutes.md`）も同じに

### Step 3 市民の提案の最初の意見（`interface/api/proposals.rs`、`process/progress.rs`、提案の画面）
- 提案に入れられる意見を1〜10件に
- 提案した人の上限は、最初の意見（`is_seed`）を除いた自分の意見で数える（`post_permission`）。参加する人は今までどおり（最初の意見を書くのは提案した人だけなので、ほかの人には影響しない）
- フォームの説明: 最初の意見は10件まで、公開のあとに別に3件書ける

### Step 4 テストと docs
- お金の年度（第1回定例会→翌年度の予算、6月→その年度、予算が無ければ出さない、決算はその前の最新）、提案の10件、公開後の3件
- ADR 0005（投稿数の上限・最初の意見）、`design/api.md`、CLAUDE.md の原則、`overview.md` の「まだ決めていないこと」、`plans/README.md`

## 実装時の変更点
- お金の API の `TopicFinances` の `fiscal_year`・`source` を null になりうる形にした（議会のトピックで、会議より前の決算が無く、予算だけがあるとき）
- 予算の欄の見出しを「この分野の今年の主な事業」から「この分野の主な事業（〇年度・予算）」にした（会議の年度の予算を出すので「今年」とは限らない）
- 最初の意見の上限の定数 `MAX_STATEMENTS`（5件）を、知らせる目安の `MANY_STATEMENTS`（15件）に置き換えた。提案の10件は `progress::PROPOSAL_SEEDS`
- 投稿の上限は、最初の意見（`is_seed`）を数えない形にした。最初の意見を書くのは提案した人だけなので、参加する人の1件には影響しない
- 「この分野のお金」の備忘（2026-10-28 の依頼）は、実装したので Claude の記憶から消した
- 確かめ: `cargo test`（新しいテストを含め、すべて通る）・clippy・frontend の lint と型チェック。コピーした DB で、令和8年の会議のトピックが「予算 2026年度・決算 2024年度」になることを確かめた
