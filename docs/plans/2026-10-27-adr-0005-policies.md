# 運用方針（トピックの寿命・投稿数・資金・提言）を ADR に記録する

## Context
フェーズ5b をマージした（PR #5）。次の開発の前に、運用の方針をユーザーと検討した。
この計画では、決めたことを ADR に記録し、まだ決めていない「提言の作り方」を案として出す。実装は別の計画にする。

### ユーザーと決めたこと（2026-10-27）
1. **トピックの寿命**: 期限つきにする
   - 投票の期限の既定は、公開から90日。議決などがあれば、運営者が早めに締め切れる
   - 締め切ったあとも結果は読める。止めるのは投票と投稿だけ
   - 会議録から作ったトピックには、議論のあった日を目立たせて出す
2. **投稿数**
   - 意見は1人1トピックあたり3件まで（承認待ちを含む）
   - 市民からのトピックは「提案」として受け付け、運営者の確認を通ったものだけを公開する（1人あたり週に1件まで）
   - Polis 本家には1人あたりの上限は無く、モデレーションで意見の数を絞っている。このアプリは「全部に投票するまで分析を見せない」作りなので、上限が要る
3. **資金**: 寄付・投げ銭は、議論に影響させない
   - 投稿数や投票は、誰でも同じにする
   - 特典は、支援者の名前の掲載（本人が同意したときだけ。意見とは結び付けない）や、収支の報告などに限る
   - 収支は公開する。政党・政治団体・候補者からの寄付は受けない
   - 行政からの出資は受けない（公平性のため）
4. **トピックの統合**: 「提言」と「第2回のトピック」の両方を、この順に作る
   - 第2回のトピックには、もとの提言へのリンクを付ける。どんなトピックが積み上がってきたかを、さかのぼれるようにする

## 提言の作り方（案。ADR では「検討中」として記録し、ユーザーと詰める）
### 提言にしてよいトピックの条件（合意点が安定したか）
- 締め切ったトピック、または、分析の対象が30人以上いるトピック
- 意見のグループが2つ以上ある
- 合意点の顔ぶれが、直近2週間の分析で変わっていない
  - 判定: 合意点の集合の重なり（ジャカード係数）が 0.8 以上
  - そのために、分析の結果の履歴を残す
### 似たトピックの候補
- 同じ分野タグを持つトピックの中から、AI が「同じ論点を扱っているもの」の候補を出す
- まとめるかどうかは、運営者が決める（AI は候補を出すだけ）
### 中身（数理とプログラムで決める。AI に文を作らせない）
- **合意点**: どのグループでも8割以上が賛成した意見。今の判定（`(A+1)/(S+2) ≥ 0.8`）をそのまま使う
- **意見が分かれた点**: あるグループでは多くが賛成し、別のグループでは多くが反対した意見
  - 合意点だけを並べると、議論の全体が伝わらないため
- 意見の文は**原文のまま**載せる。それぞれに、元のトピック・参加した人数・賛成の割合を添える
- 関わり方の内訳（二次秘匿済み）、期間、元のトピックへのリンクも載せる
- AI が書いてよいのは、中立な見出しと短い前書きだけ。これも下書きにし、運営者が確かめてから公開する（会議録のトピックと同じ）
### 提言を、別の提言にまとめてよいか
- まとめてよいことにする。ただし、下の提言の文章はまとめに使わず、その元になった**意見（原文と数字）をたどってまとめる**
  - 要約の要約を重ねると、もとの投票から離れていくのを防ぐため
- 提言のつながりは、木の形でたどれるようにする（循環は作れないようにする）
### 出口
- 印刷・PDF にでき、陳情・パブリックコメント・市長への手紙などに使える形にする
- 第2回のトピック: 提言の合意点と、意見が分かれた点を最初の意見にして、新しい人にも投票してもらう

## やること
- **`docs/adr/0005-topic-lifecycle-and-funding.md`** を書く
  - 決めたこと（1〜4）と、理由
  - 提言の作り方の案（「検討中」と明記）
- CLAUDE.md の原則の節に、要点を足す
  - トピックは期限つき
  - 意見は1人1トピック3件まで
  - お金で議論への影響を変えない
- メモリに、資金の原則（お金で議論への影響を変えない）を足す
- コミットは `docs: トピックの寿命・投稿数・資金の方針を ADR 0005 に記録`
  - main は直接触らず、ブランチ `docs/adr-0005` で PR にする
- 実装の計画は、ユーザーと順番を決めてから作る
  - 寿命と投稿数の上限は、フェーズ6（認証）と一緒にするのがよいと思う。上限は1人を見分けられて初めて意味がある
  - 提言は、その後にする
