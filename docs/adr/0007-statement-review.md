# ADR 0007: 意見の審査（害・人物・投票できる意見か・似た意見）

- 状態: 承認（2026-10-28）
- 計画: `docs/plans/2026-10-28-phase6b-participation-rules.md`
- 関連: ADR 0003（LLM の運用。この ADR で「AI に送るもの」を改める）、ADR 0004（会議録・公人の扱い）、ADR 0005（似た意見の案内・投稿数）

## 背景

フェーズ6a の動作確認で、今のモデレーション（ADR 0003）では次の投稿が公開された。

- 性的な内容（「スケベしたい」）。基準に公序良俗の項目が無かった
- 公人をほめる文（「（市長の氏名）はいいやつだ」）。基準は人格攻撃だけを見ていた
- 役職名での進退の要求（「市長には辞任してほしい」）。公務への批判は公開する、という基準どおり
- 投票できない文・トピックと無関係な文（「わからない」）。基準が「話題から外れた意見も公開する」としており、AI はトピックの中身を知らなかった

このサービスは、市民が政策について合意点と意見の分かれ目を探す場である。投票の対象は「論点」であり、人ではない。
また、ADR 0005 の「似た意見の案内」には、トピックの既存の意見と比べることが要る。

## 決定

### 審査の観点
投稿を、1回の AI の呼び出しで次の4つの観点から判定する（観点ごとに別々に答えさせ、プログラムでまとめる）。

1. **害・公序良俗**: 暴言・脅迫・差別・誹謗中傷・私人の個人情報（ADR 0003 のとおり）に加えて、性的な内容、違法な行為をすすめるもの、自分や他人を傷つけることをすすめるもの、宣伝・スパムを非公開にする
2. **人物**: 特定の人物の評価・進退・人柄が主の意見は、**ほめてもけなしても**非公開にする。氏名でなく役職名で特定できるもの（「市長には辞任してほしい」）も同じ
   - 公人の政策・公務・議会での発言への賛否、役職や制度そのものへの意見は公開する（ADR 0003 の「公人の公務への批判は公開」は保つ）
   - 理由: 政策の議論を深める場であり、人への賛否は分断を生みやすい。公人の進退は、リコールや選挙など正式な手続に委ねる。ほめるのもけなすのも同じに扱うので、立場では判断しない
3. **投票できる意見か・トピックとの関係**: 賛成・反対のしようがない文（「わからない」、質問だけ、単語だけ）と、トピックとはっきり無関係なものは非公開にし、書き直しの案内を返す。少しでも関係するもの（広げた提案や別の案）は公開し、迷ったら公開する（運営者の確認を増やさない）
4. **似た意見**: 同じ立場で同じことを言っている既存の意見があれば、保存せずにその意見への投票を案内する（ADR 0005）。立場が逆のもの、少しでも違うものは別の意見として通す

まとめ方: どれかで非公開なら非公開 → どれかで判断に迷えば確認待ち（flagged）→ 重複なら案内 → それ以外は公開。

### 公人の氏名はプログラムでも確かめる
その自治体の `public_officials` の氏名がそのまま含まれていたら、AI に送る前に非公開にする（ADR 0004 の会議録の取り込みと同じ確かめ方。API キーが無い環境でも効く）。名字だけの一致は、地名や普通の言葉と重なるので見ない（AI の「人物」に任せる）。

### AI に送るもの（ADR 0003 を改める）
- 送るのは、投稿の本文、**トピックのタイトルと説明**、**そのトピックの承認済みの意見の本文**（番号を振る。最大300件）。どれも公開しているものだけ
- 参加者の ID、関わり方、意見を書いた人は、今までどおり送らない
- 投稿フォームの説明も「送るのは本文とトピックの公開済みの内容だけで、あなたを識別する情報は送りません」に改める

### 変えないこと
- 主張の内容や政治的な立場では判断しない
- 判定できないとき（通信の失敗・費用の上限）は pending のまま残し、自動承認しない。refusal は flagged
- API キーが無ければ全件承認（似た意見の判定もしない）。公人の氏名の確かめだけは効く

## 理由
- 1回の呼び出しにまとめるのは、どの観点にもトピックの中身が要り、別々に呼ぶと同じものを何度も送るため。投稿した人の待ち時間も1回分で済む。観点ごとに答えを分けるので、評価も観点ごとに見られる
- 似た意見の判定は、立場の違いを読み分ける必要があり、ベクトルの近さだけでは決められない。候補を集める部分（ベクトル化や自製の類似度）は、意見が増える「意見の取りまとめ」のフェーズで検討する

## 影響
- 投稿の API の結果に `duplicate`（と案内する意見）と、非公開の理由の種類を足す
- 1件の投稿で送る文字数が、そのトピックの意見の数だけ増える（意見100件で約1.4万文字。Sonnet 5.5 で1件 0.02 ドル前後。基準の部分はプロンプトキャッシュに乗る）
- 評価データ（`evals/moderation.jsonl`）に、トピックと既存の意見を持たせる
