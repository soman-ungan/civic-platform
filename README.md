# civic-platform

自治体の議事録・予算・決算を可視化し、Polis の思想に基づく合意形成の場を提供する Web アプリです。
栃木県大田原市をパイロット自治体として、多自治体に対応した構成で開発しています。

- 設計: [docs/grand-design.md](docs/grand-design.md)
- 開発の指針・コマンド: [CLAUDE.md](CLAUDE.md)
